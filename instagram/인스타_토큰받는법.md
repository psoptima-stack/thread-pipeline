# 인스타그램 자동 게시 준비 (한 번만 하면 됩니다)

필요한 값은 딱 두 개입니다.

| 이름 | 정체 | 넣는 곳 |
|---|---|---|
| `IG_USER_ID` | 인스타그램 **비즈니스 계정 ID** (숫자, @아이디 아님) | GitHub Secret |
| `IG_ACCESS_TOKEN` | 인스타그램 권한이 붙은 **페이지 액세스 토큰** | GitHub Secret |

---

## 0. 먼저 확인할 것

- 인스타그램 계정이 **프로페셔널(비즈니스/크리에이터)** 로 전환되어 있어야 합니다. ✅ 완료
- 그 인스타그램 계정이 **페이스북 페이지와 연결**되어 있어야 합니다.
  (페이스북 자동 게시에 쓰는 그 페이지와 같은 페이지)

인스타 앱의 `프로필 편집 → 페이지` 메뉴는 앱 버전에 따라 **안 보일 수 있습니다.**
그럴 때는 페이스북 쪽에서 연결하는 게 확실합니다.

### 방법 A — Meta Business Suite (권장)

1. PC 브라우저로 https://business.facebook.com 접속
2. 왼쪽 위에서 **해당 페이지**가 선택되어 있는지 확인
3. 왼쪽 아래 **설정(톱니)** → **계정** → **Instagram 계정**
4. **연결** → 인스타 로그인 → 페이지 선택

### 방법 B — 페이스북 페이지 설정

1. PC에서 facebook.com → 왼쪽 **페이지** → 내 페이지 선택
2. **설정 및 개인정보** → **설정**
3. **연결된 계정(Linked accounts)** → **Instagram** → **계정 연결**

> ⚠️ 인스타 앱의 **설정 → 계정 센터**에서 하는 연결은 *개인 프로필끼리* 묶는 기능이라
> API에서는 잡히지 않습니다. 반드시 **페이지 ↔ 인스타** 연결이어야 합니다.

연결 여부는 화면 대신 3단계의 API 응답으로 확인하는 게 가장 정확합니다.

## 1. 앱에 인스타그램 권한 추가

페이스북 게시 때 만든 앱을 그대로 씁니다.

1. https://developers.facebook.com/apps → 쓰던 앱 선택
2. 좌측 **제품 추가** → **Instagram Graph API** 추가
   (이미 있으면 넘어갑니다)

---

## 2. 토큰 발급

1. https://developers.facebook.com/tools/explorer 접속
2. 오른쪽 위에서 앱 선택
3. **권한(Permissions)** 에서 아래 4개를 체크
   - `pages_show_list`
   - `pages_read_engagement`
   - `instagram_basic`
   - `instagram_content_publish`
4. **Generate Access Token** → 페이스북 로그인 → 페이지·인스타 계정 허용
5. 나온 토큰을 복사 (이건 아직 **사용자 토큰**, 유효기간 1~2시간)

### 2-1. 장기 토큰으로 바꾸기

Explorer 주소창 대신 브라우저에서 아래 주소를 직접 열어도 됩니다.
`{앱ID}` `{앱시크릿}` `{방금복사한토큰}` 을 바꿔 넣으세요.

```
https://graph.facebook.com/v21.0/oauth/access_token?grant_type=fb_exchange_token&client_id={앱ID}&client_secret={앱시크릿}&fb_exchange_token={방금복사한토큰}
```

돌아온 `access_token` 이 **60일짜리 장기 사용자 토큰**입니다.

### 2-2. 페이지 토큰으로 바꾸기 (만료 없음)

```
https://graph.facebook.com/v21.0/me/accounts?access_token={장기사용자토큰}
```

내 페이지 목록이 나옵니다. 쓰는 페이지의 `access_token` 값이 **`IG_ACCESS_TOKEN`** 입니다.
이 페이지 토큰은 비밀번호를 바꾸지 않는 한 만료되지 않습니다.

> 같은 목록의 `id` 는 페이지 ID입니다. 다음 단계에서 씁니다.

---

## 3. IG_USER_ID 알아내기

```
https://graph.facebook.com/v21.0/{페이지ID}?fields=instagram_business_account&access_token={페이지토큰}
```

응답이 이렇게 나옵니다.

```json
{ "instagram_business_account": { "id": "17841400000000000" }, "id": "1234567890" }
```

`instagram_business_account.id` 가 **`IG_USER_ID`** 입니다.

> 여기가 비어 있으면 1단계의 **인스타↔페이지 연결**이 안 된 상태입니다.

---

## 4. GitHub Secret 등록

저장소 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

| Name | Value |
|---|---|
| `IG_USER_ID` | 3단계에서 얻은 숫자 |
| `IG_ACCESS_TOKEN` | 2-2에서 얻은 페이지 토큰 |

---

## 5. 잘 되는지 확인

1. 저장소 → **Actions** → **발행일 인스타그램 자동 게시** → **Run workflow**
2. `date` 에 게시할 날짜(예: `2026-08-18`) 입력 → 실행
3. 로그에 `[완료] ... 인스타그램 게시 성공 media_id=...` 가 뜨면 끝입니다.

로컬에서 미리 보고 싶다면 게시 없이 확인만 할 수 있습니다.

```bash
python instagram/make_cards.py --date 2026-08-18
python instagram/post_to_instagram.py --date 2026-08-18 --dry-run
```

## 자주 나는 오류

| 메시지 | 원인 / 해결 |
|---|---|
| `The user is not an Instagram Business` | 인스타가 프로페셔널이 아니거나 페이지 연결이 끊김 |
| `(#200) Requires instagram_content_publish` | 2단계 권한 체크를 빠뜨림. 토큰 다시 발급 |
| `The image could not be downloaded` | 카드 이미지가 아직 GitHub에 안 올라갔거나 저장소가 비공개. 워크플로는 커밋·푸시 후 게시하도록 되어 있음 |
| `Only JPEG images may be used` | 카드가 PNG. `make_cards.py` 는 기본이 jpg이니 `--format` 을 png로 주지 말 것 |
| `Media ID is not available` | 이미지 처리 중 발행 시도. 스크립트가 자동으로 기다리므로 재실행하면 해결됨 |

## 하루 한도

인스타그램은 **24시간에 25개 게시물**까지만 API로 올릴 수 있습니다.
하루 한 편 발행이라 걸릴 일은 없습니다.
